# 사내비 새 계정 인수인계 문서

작성일: 2026-08-10
대상: 새로운 Codex 계정에서 `saneB` 프로젝트를 이어서 운영·개발하는 담당자
문서 성격: 저장소 기준선, 제품 정책, 구현 현황, 운영 환경, 보류 Gate를 연결하는 내부 인수인계 자료

## 1. 이관 목적

새 계정은 이전 대화와 Codex 로컬 메모리를 자동으로 상속하지 않는다고 가정한다. 따라서 다음 우선순위로 프로젝트 문맥을 복원한다.

1. 현재 파일시스템과 Git 상태
2. 루트 `AGENTS.md`
3. 이 인수인계 문서
4. DB 모델과 API 계약
5. 제품 로드맵과 클라이언트 원문
6. 운영 환경과 배포 결과

과거 대화 요약이나 문서와 현재 코드가 충돌하면 현재 코드, Flyway migration, API 구현, 테스트 결과를 우선한다. 충돌은 임의로 수정하지 않고 차이와 영향도를 먼저 보고한다.

## 5. 제품 기준

### 서비스 이름

- 대외 서비스명: `사내비`
- 내부 프로젝트·패키지·저장소명: `saneB`
- 사용자 화면과 고객 문서에서는 `사내비`를 우선 사용한다.
- 패키지명과 내부 시스템명은 별도 영향도 검토 없이 변경하지 않는다.

### 제품 목적

사내비는 소상공인, 개인, 배우자, 자녀, 부모 조건에 맞는 정부지원사업을 탐색하고, 기본정보 입력부터 후보 확인, 구독, 상담, 증빙 입력, 최종 매칭, 신청 진행, 결과 관리까지 연결하는 운영 플랫폼이다.

### 핵심 정책

- 완전 개발을 목표로 하되 DB-first와 API 계약 우선 원칙을 유지한다.
- 사용자 최초 행동은 기본정보 입력이다.
- 서류·전자증명 데이터는 API 자동 수집이 아니라 사용자 전달 후 내부 직원 또는 파트너가 수동 입력·확인한다.
- 검증은 사용자 확인 장치이며 모든 진행의 절대 승인 Gate로 사용하지 않는다.
- 서버의 권한 검증, 입력 검증, 상태 전이는 반드시 유지한다.
- 기본정보 기준 후보와 서류 기준 정밀 후보를 구분한다.
- 최종 진행 공고는 관리자가 조건 적합성과 마감일을 확인해 선택한다.
- 추천도, 선정확률, 자동 점수, AI 자동 승인·탈락은 도입하지 않는다.
- 외부 공고 수집 결과는 자동 활성화하지 않는다.

## 7. 사용자 전체 흐름

1. 회원가입 전 `간단 결과 확인하기`
2. 회원가입과 로그인
3. 대표자·사업·가족 기본정보 입력

8. 공고 조건과 확인값을 비교해 정밀 후보 정리
9. 관리자가 마감일 오름차순으로 최종 진행 공고 선택

## 8. 기술 구조

### 기술 스택

- Java 21
- Spring Boot 3.4.5
- Gradle Wrapper
- Spring Security
- MyBatis 3.0.4
- PostgreSQL / Aurora PostgreSQL
- Flyway
- Thymeleaf
- Bootstrap 5
- Jsoup
- Ubuntu, systemd, AWS CodeDeploy

### 계층 구조

`Controller -> Service -> ServiceImpl -> DAO -> Mapper XML -> PostgreSQL`

- Controller는 URL, 요청·응답, DTO 변환만 담당한다.
- ServiceImpl은 transaction과 업무 규칙을 담당한다.
- DAO는 Mapper 호출만 담당한다.
- SQL은 Mapper XML에 작성한다.
- `SELECT *`, MyBatis `${}`, Thymeleaf `th:utext`는 금지한다.

### 데이터 원칙

- Flyway migration이 schema source of truth다.
- 운영 migration과 local/dev seed를 분리한다.
- 기존 migration을 수정하지 않고 additive migration을 추가한다.
- 개인정보 원문과 감사 로그 metadata를 분리한다.
- 운영 secret과 외부 API key는 환경변수 또는 Secrets Manager로만 주입한다.

### API 원칙

- 모든 내부 API는 `/api/v1/...`와 `ApiResponse<T>`를 사용한다.
- 목록은 `PageResponse<T>`를 사용한다.
- 기존 v1 의미를 깨는 변경은 `/api/v2/...`로 분리한다.
- 브라우저가 상태, 역할, route를 추측하지 않는다.

## 10. 외부 공고 수집 정책

### 공통 흐름

`수집 -> 중복 확인 -> 검수 대기 -> 운영자 조건 입력 -> 검수 완료 -> 활성`

- 기업마당, 정부24, 지자체 수집 원문을 하나의 관리자 흐름에서 관리한다.
- 수집 원문과 운영 공고 데이터를 분리한다.
- 하이라이트와 중복 후보는 참고 데이터이며 자동 조건 저장에 사용하지 않는다.
- 종료된 공고는 신규 활성 후보에서 제외한다.

### 지자체 수집

- 공식 고시·공고 또는 지원사업 게시판을 우선한다.
- 일반 공지는 정적 지원사업 키워드 필터를 적용한다.
- 보도자료와 의미 미확인 출처는 활성화하지 않는다.
- 수집 파서는 사용자가 선택하지 않으며 시스템 seed와 격리 QA로 관리한다.
- 바로가기는 사용자의 브라우저에서 `noticeUrl`을 연다.
- 서버 수집기는 `collectionEndpointUrl`을 우선하고 없으면 `noticeUrl`을 호출한다.
- 브라우저 접속 성공과 EC2 Java 수집 성공은 동일한 판정이 아니다.

### 알려진 후속 과제

V62에는 QA 보류 출처 13개가 기록되어 있다. 정적 QA 보류값과 실제 최신 수집 실패가 같은 `최근 진단`으로 보일 수 있으므로 다음 보정이 필요하다.

1. `QA 보류`와 `실제 자동수집 실패`의 진단 출처 분리
2. 진단 발생 시각과 진단 출처 표시
3. 파서와 분리된 서버 연결 재검사 기능
4. 재검사 성공 시 오류 해제 정책

## 11. 결제와 외부 서비스 보류 Gate

### TossPayments

- 월 자동결제 기준 금액: 12,900원
- 현재 구현: mock 결제와 provider 중립 DB/API
- 보류: billing key 발급·저장, 승인 API, webhook 검증, 자동 청구 재시도, 실제 환불
- 필요 정보: 상점 계약 상태, client key, secret key, webhook URL, 성공·실패 redirect URL, 정기결제 정책
- key는 코드·문서·DB에 저장하지 않는다.

### 기업마당·정부24

- provider client와 관리자 수집 UI는 존재한다.
- 새 계정은 운영 환경의 API key 설정 여부와 실제 응답 필드를 다시 확인한다.
- 실제 원문과 운영 공고를 분리하고 운영자 승인 전 자동 활성화하지 않는다.

### 외부 AI

- 기본값은 외부 호출이 없는 `LOCAL_SAFE`다.
- 개인정보 원문 외부 전송 금지와 provider 계약이 승인되기 전 외부 AI를 연결하지 않는다.

## 12. 배포·운영 기준

### 배포 경로

`GitHub master push -> GitHub Actions -> Java 21 bootJar -> S3 bundle -> AWS CodeDeploy -> EC2 systemd saneb`

GitHub Actions는 다음 repository variables를 사용한다.

- `AWS_REGION`
- `AWS_DEPLOY_BUCKET`
- `AWS_CODEDEPLOY_APPLICATION`
- `AWS_CODEDEPLOY_DEPLOYMENT_GROUP`
- `AWS_GITHUB_ACTIONS_ROLE_ARN`

실제 값은 GitHub·AWS 콘솔에서 확인하며 문서에 복사하지 않는다.

### 운영 DB와 secret

- Aurora PostgreSQL, prod profile, `sslmode=require`
- EC2 instance role이 Secrets Manager의 RDS managed secret을 읽는다.
- `/home/ubuntu/app/app.env`에는 secret 원문 대신 secret ARN과 비밀이 아닌 설정만 둔다.
- `SANEB_BOOTSTRAP_ADMIN_ENABLED`는 일반 운영에서 `false`를 유지한다.

### 주요 환경변수 그룹

- DB: `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, `DB_POOL_*`, `FLYWAY_CONNECT_RETRIES`
- 파일: `STORAGE_ROOT`, `SANEB_MAX_UPLOAD_*`
- 주소: `JUSO_API_ENABLED`, `JUSO_API_BASE_URL`, `JUSO_API_KEY`
- 외부 공고: `BIZINFO_*`, `GOV24_PUBLIC_SERVICE_*`, `SANEB_ANNOUNCEMENT_SOURCE_*`, `SANEB_LOCAL_GOV_NOTICE_*`
- 운영: `SANEB_RATE_LIMIT_*`, `SANEB_INACTIVITY_REMINDER_*`, `SANEB_APP_LOG_*`
- AI: `SANEB_AI_PROVIDER_CODE`, `SANEB_AI_MODEL_CODE`
- 관리자 bootstrap: `SANEB_BOOTSTRAP_ADMIN_*`
