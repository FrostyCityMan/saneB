## 구현 우선순위

1. 검증 대체 URL이 확보된 기관부터 URL을 교체하고 재QA합니다.
2. JavaScript 상세 링크, data 속성 링크, 두 자리 연도 날짜를 공통 정적 프로필로 보강합니다.
