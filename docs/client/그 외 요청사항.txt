그 외 요청사항

1. 검수 계정은 별도 생성 요청드립니다.
슈퍼관리자 권한은 제외하고,
테스트 데이터 기준 조회 및 흐름 확인만 가능하도록 구성 요청드립니다.
2.샘플 공고는 실제 운영 기준으로,
조건 유형별 테스트가 가능하도록 구성 요청드립니다.

예:
- 업력/매출 조건형
- 지역 제한형
- 가족 조건형
- 중복 제한형
- 예산 소진형
3. 공고 입력 항목은 운영자 기준 한글 라벨 우선 적용 요청드립니다.
자동 기본값 및 도움말 문구도 함께 적용 요청드립니다.
4. 결제/구독 기능은 MVP 1차에 포함 요청드립니다.
초기에는 복잡한 구조 없이 월 단순 구독 구조로 적용 요청드립니다.
5. 상담 예약은 MVP에서는 자동 예약 기능 없이,
상담 요청 접수 후 운영자가 직접 배정하는 수기 운영 방식으로 진행 요청드립니다.
6. 회원가입 전 임시 후보 확인 API 추가 요청드립니다.
가능 후보 수 및 예상 지원금 범위 정도만 노출하는 구조로 요청드립니다.
7. 장기 미진행/TM 재접촉 기능은 MVP 최소 수준 포함 요청드립니다.

기본 기준:
- 24시간 미진행 → 1차 리마인드
- 72시간 미진행 → 재안내
- 7일 이상 미진행 → 장기 미진행 분류
- 14일 이상 미진행 → TM 재접촉 대상 분류

사용자가 행동 완료 시 이후 리마인드는 자동 중단되는 구조로 요청드립니다.
