[3] 서비스 브리핑

[브리핑 핵심 내용]

- 사업자 본인만 확인하는 구조가 아닙니다.
- 배우자 / 자녀 / 부모 기준까지 함께 확인합니다.
- 정책자금 / 지원금 / 보조금 가능 여부를 지속적으로 확인합니다.
- 실제 진행 가능한 항목 중심으로 안내합니다.
- 단계별 진행 관리 구조를 제공합니다.

[가격 체감 브리핑]

- 월 12,900원 기준
- 가족 4명 확인 시
- 1인당 하루 약 100원 수준으로 지속 확인 가능

[행동 버튼]

- 결과 계속 확인하기

━━━━━━━━━━━━━━━━━━

[가족 기준 노출]

- 사업자 기준 가능 항목
- 배우자 기준 가능 항목
- 자녀 기준 가능 항목
- 부모 기준 가능 항목

[안내 문구]

현재 사업 및 가족 정보 기준으로
진행 가능한 항목이 확인되었습니다.

하지만 지원사업 / 정책자금 / 보조금/지원금은
공고 변경, 신규 공고 등록, 조건 변경,
가족 상황 변경 등에 따라
가능 여부가 계속 달라질 수 있습니다.

이 서비스는 단순 1회 조회가 아니라

사업자 / 배우자 / 자녀 / 부모 기준까지
지속적으로 신규 가능 항목을 확인하고,
실제 진행 가능한 항목 중심으로
단계별 진행 관리를 제공합니다.

또한 진행 단계별 리마인드,
신규 가능 항목 알림,
전자증명 기반 상태 확인 구조를 통해
놓칠 수 있는 지원 항목까지
지속적으로 확인할 수 있습니다.
최대6명의 지원사업 / 정책자금 / 보조금/지원금
월12.900원으로 이용할수 있습니다.


※ 현재 결과는 입력 기준 참고 결과이며
실제 조건 확인 후 달라질 수 있습니다.

4. 현재 MVP 핵심 원칙

- 일반 유입 / TM 유입 분리 운영
- 가족 포함 1차 매칭 구조 사용
- 실제 진행 가능한 항목 중심 구조
- 회원 입력보다 전자증명 기준 우선
- 체크리스트 기반 진행 구조 사용
- 현재 해야 할 행동 1개 중심 구성
- 단계 완료 후 다음 단계 이동 구조
- 신규 가능 항목 지속 탐색 구조
- AI 자동판단 없음
- AI 자동해석 없음
- AI는 운영 보조 역할만 사용
- 자동 추천 / 자동 우선순위 계산 없음
- 예외 / 제한 항목 체크 시 정책자금 매칭 제외
