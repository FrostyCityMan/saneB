## 공고 입력 연계의 정확한 의미

첨부 텍스트를 적재한다고 모든 입력 필드를 자동 완성하는 것은 아니다. 첨부 검수 정책이 적용된 근거를 관리자가 확인한 후 별도 초안 생성 요청을 실행하면 제목·기관·수집 본문·신청 기간·확정 다중 분류가 비활성 DRAFT로 복사된다. 이후 조건 입력과 후속 승인이 필요하다. COLLECT_ONLY만으로 이 최종 전환 Gate를 충족했다고 보고하지 않는다.

- UI 시각 변경은 없다. 실제 운영 단건 예약·조회·문단 이동·구간 근거 및 콘솔을 확인했으며 모바일/스크린리더/모든 역할의 전체 회귀를 새로 실행한 것은 아니다.
