# 첨부 추출기 1.0.1 — PDF 사용 자원 판정과 HWPX 텍스트 순서

## 범위 / Gate

제목 → 정제 본문 → 실제 첨부 텍스트 → 최종 관리자 검증의 P3 품질 보완이다. 전체 Gate0~8/ATT-001~062는 미완료다. 첨부 엔진6종/프로필17개/전용 본문16기관/형식3종/V83은 변경하지 않는다.

## 확인한 문제

1. PDF 1.0.0은 페이지 자원 사전에 XObject가 하나라도 있으면 PARTIAL_TEXT로 처리했다. 문서가 그리지 않는 이미지 자원도 영향을 주었다. 반대로 자원 사전 없이 content stream에 포함된 인라인 이미지와 누락된 XObject 그리기 명령은 텍스트가 있으면 COMPLETE_TEXT가 될 수 있었다.
2. HWPX 1.0.0은 중첩 문단을 먼저 기록한 뒤 부모 문단의 앞뒤 텍스트를 합쳐 기록했다. `앞 → 셀 → 뒤`가 `셀 → 앞뒤`로 바뀌었다. 이는 분류·근거 위치의 입력 품질 문제다.
3. 신규 합성 회귀8건 중 기존 구현에서5건이 실패하여 재현했다. 이 결과는 양평 실파일의 PARTIAL_TEXT 원인을 모두 규명했다는 의미가 아니다.

## 변경 계약

- PDF는 PDFBox의 실제 `Do`/`BI` 연산을 읽는 시점에 불완전 가능성을 기록한다. 미사용 자원 사전은 판정 근거가 아니다. 그린 이미지·인라인 이미지·Form·누락된 그리기 대상은 계속 부분 추출이다. 빈 문서/스캔은 OCR_REQUIRED, 빈 페이지가 섞인 문서는 PARTIAL_TEXT를 유지한다.
- Form을 텍스트 전용으로 확인한 구현은 아니다. 이미지가 장식이라고 추정하거나 픽셀 수·위치로 제외하지 않는다. 기존 PDF 블록의 문맥 신뢰는 false로 유지한다.
- HWPX는 자식 문단 진입 전에 부모 텍스트를 먼저 기록하고 자식 이후 남은 텍스트를 별도 구간으로 기록한다. 중첩 앞뒤는 서로 다른 `paragraph:<n>:segment:<m>` locator/scope를 사용한다. 문단 앞뒤를 AND 문맥으로 합치지 않는다.
- 중첩 자체는 텍스트 누락이 아니다. 실제 한 문단의 연속된 구간을 분리하여 원문 순서/구간 경계/전체 텍스트를 보존한 경우 scopeReliable=true이며, 다른 누락 사유가 없다면 COMPLETE_TEXT로 판정한다. 독립 셀 문단과 텍스트 없는 바깥 컨테이너는 기존 계약을 유지한다. 이미지/OLE/수식·replacement character가 있으면 여전히 부분 추출이며 한도 초과·외부 entity 차단도 그대로다. 이 판단은 표의 시각적 관계나 자격조건의 의미를 추론하는 것이 아니다.
- 추출기 JAR manifest/IPC/서버 실행 식별 버전은1.0.1로 맞춘다. 실행 지문에 새 JAR/버전이 포함되므로1.0.0 QA 근거·정책을 새 결과로 재사용할 수 없다. 이전 버전 거부 시험을 유지한다.
- DB 컬럼/기존 migration/v1 및 v2 응답 필드 변경은 없다. 기존 추출 결과는 불변이다. 새 locator·텍스트 hash는 새 버전의 실행에만 생성된다. 자동 재추출/정책 게시/ENFORCE/기존 데이터 적용은 실행하지 않는다.
- 공식 worker 관측에는 원문 없이 분할 문단 블록 수와 신뢰 미확보 블록 수만 추가하여 실제 파일에서 적용된 결과를 확인한다. 이 수치가 완전성·역할 승인 근거를 대체하지 않는다.

## 검증

- 신규 회귀11건: 미사용 이미지, 실제 이미지, 인라인 이미지, 사용한 Form, 누락된 그리기 대상, 중첩 앞/셀/뒤 순서, 다중 중첩·형제 셀, 텍스트 없는 컨테이너, 중첩 순서 복구 후에도 이미지/OLE/수식3종의 부분 추출 유지. 코드 포인트 offset/독립 locator/신뢰 상태도 대조한다.
- 기존 추출13건 및 런타임 합성 fixture12건을 유지한다. 새 버전이 성공/실패 IPC 모두에 반환되는지 확인한다.
- 배포 패키지는 서버 실행 버전과 일치한 추출기 JAR을 요구한다. 런타임 QA는 이전1.0.0 응답을 명시적으로 거부한다.
- 로컬 전체 회귀·bootJar·패키징, 같은 SHA Linux 실행, 설치된 런타임 실파일 worker/DB/API 재검증은 각각 분리하여 기록한다. 미실행 항목은 통과로 계산하지 않는다.

## 잔여

현재 양평 PDF/HWPX의 PARTIAL_TEXT가 전부 해소됐다고 주장하지 않는다. 실제 이미지/OLE/수식 등 누락 사유가 남으면 그 사유의 검수는 필요하다. PDF Form 내부의 텍스트 완전성·표/다단의 신뢰 범위, 공식 기대값·전체 수집처 적용성, 정책 활성화·기존 데이터·운영 업무 E2E는 계속 장기 goal 범위다.
