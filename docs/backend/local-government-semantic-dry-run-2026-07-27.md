### 공식 고시·공고 URL 후속 보정

V57은 운영 전체 활성화 전에 밀양시와 함양군의 출처 의미를 다시 확인하여 일반 공지에서 공식 고시·공고로 보정한다.

| 게시판 유형 | 수집 정책 | V57 적용 후 출처 수 |
|---|---|---:|
| 고시·공고 | 전체 수집 | 30 |
| 지원·모집 | 전체 수집 | 10 |
| 일반 공지 | 키워드 선별 | 203 |
| 보도자료 | 제외 | 1 |

기존 293건 dry-run 결과는 V57에서 삭제하거나 일괄 재분류하지 않는다. 과거 일반 공지에서 키워드로 선별된 유효 후보와 운영 이력을 보존하고, 두 출처의 공식 URL 전환 이후 신규 수집 건부터 고시·공고 정책을 적용한다.

전수 QA에서 안양시 구형 새올 수집 endpoint가 반복 timeout됐고, 운영 격리 시험 `ASRUN-000011`에서도 `TRANSPORT_FAILED`가 재현됐다. 동일 게시물을 제공하는 공식 HTTPS 화면은 브라우저와 TLS 1.2 요청에서 정상 응답하지만 TLS 1.3 협상을 서버가 종료한다. V57은 현재 공식 고시공고 화면을 전용 `TLS12_BROWSER` 요청과 기존 `SPRING_BBS`로 직접 수집하도록 보정한다.

거제시는 공식 고시공고 목록 URL에서 페이지 번호가 생략되면 WAF가 HTTP 주소로 302 이동시켰다. V57은 `startPage=1`을 명시해 HTTPS 200 응답을 유지하고 게시판 유형을 `LEGAL_NOTICE`로 확정한다.

남동구는 기존 일반 새소식 URL이 403을 반환했다. 지원사업 전용 목록도 확인했지만 등록일 필드가 없어 이번 수집 계약의 필수값을 충족하지 못했다. V57은 제목·작성일·상세 URL을 모두 제공하는 남동구청 공식 고시공고 목록으로 교체하고 `LEGAL_NOTICE/COLLECT_ALL`로 확정한다.

속초는 공개 새올 고시공고를 수집하면서 일반 공지로 분류돼 있었다. V57은 `LEGAL_NOTICE/COLLECT_ALL`로 바로잡고 간헐적으로 느린 공개 endpoint에 기존 `LEGACY_BROWSER`를 적용한다. 남동구와 울산 중구에는 기존 `BROWSER_HTTP1`을 적용해 WAF의 비브라우저 요청 차단을 줄인다.

기존 사용 중 출처 21곳 중 경기도청 `LGS-000084`는 보도자료 URL이었다.
V56 적용 시 이 출처를 제외·중지하고 실제 수집 대상은 20곳이 된다.
검단구청 `LGS-000063`은 2026-07-01 구 신설 이후 기존 공지 URL이
404로 전환되어 공식 고시공고 URL로 보정했다. 서버군의 세션 고정이
필요해 기존 휴리스틱 파서와 `SESSION_BROWSER` 전송 프로필을 사용한다.

## 6. 적용 정책

- `ACCEPTED`와 `REVIEW_REQUIRED`만 기본 검수대기 목록에 포함한다.
- `EXCLUDED`는 운영 공고와 연결되지 않은 경우 `ARCHIVED`로 이관한다.
- 운영 공고와 이미 연결된 원문은 자동 삭제하거나 연결을 끊지 않는다.
- 수집 실행, URL별 결과, 감사 로그는 보존한다.
- QA 산출물 전체 삭제 API는 이번 작업에서 호출하지 않는다.
- 시험 데이터 정리는 별도 식별 근거가 있는 경우에만 수행한다.
