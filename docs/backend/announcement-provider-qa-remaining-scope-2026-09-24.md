SSM 명령 Success는 진단 프로그램 정상 종료이며 수집 성공이 아니다. 실행 환경에 따라 다른 단계의 실패가 확인됐으므로 단일 원인·인증서 만료·철원 서버 장애로 단정하지 않는다. 같은 조건의 추가 요청은 중단한다. 다음은 연결/인증서 상태 변화 근거 또는 해당 출처 운영자의 점검 결과 후 재검증이다. TLS 검증 비활성화·HTTP 전환·타임아웃 확대·대체 호스트 자동 선택으로 우회하지 않는다.

새 진단 스크립트 `scripts/qa/probe-cheorwon-transport.py`는 고정host/path만 사용한다. DNS의 모든 IPv4가 공인 주소인지 확인하고 선택 주소에 연결을 고정하며 TLS SNI/인증서 검증을 유지한다. 회당 요청 예약1·최대 응답1MiB·전체15초·CPU1개/5초·메모리128MiB다. 원문은 메모리에서 구조 개수만 산출하고 파일/URL/텍스트/예외 원문을 반환하지 않는다. 소속 관계를 검증하지 않은 구조 개수를 본문·첨부 성공으로 처리하지 않는다. 서울2회는 보수적으로 요청 예약2/응답 예산2MiB로 기록하며 실제 HTTP 전송/응답은0이다. 로컬 연결 진단은 별도 예약1/1MiB다.
