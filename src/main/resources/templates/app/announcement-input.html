사업자 지원

기본정보 조건은 현재 매칭 공고에 사용하고, 서류 기준 항목을 선택한 조건은 전체 서류 입력 후 최종 매칭에 사용합니다. 업태와 종목은 통계청 한국표준산업분류(KSIC) 코드로 표준화해 업종 조건에 입력합니다. 조건으로 사용할 수 없는 서류 항목은 필요 서류 또는 동적 입력 항목으로 요청한 뒤 담당자가 확인합니다.

업종 조건

업태/종목 텍스트를 그대로 비교하지 않고 KSIC 코드 기준으로 판단합니다.

수치 조건

조건으로 설정 가능한 숫자, 금액, 날짜 항목만 표시합니다.
