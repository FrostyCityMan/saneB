아직 계획을 조회하지 않았습니다.

2. 실행 이력

서버 실행 설정이 꺼져 있거나 설치 확인이 실패해도 기존 이력 조회와 취소는 별도입니다. 자동 새로고침은 하지 않습니다.

3. 선택한 실행과 모든 항목

아직 실행을 선택하지 않았습니다.

전체 항목 수와 현재 페이지 수를 구분합니다. 항목 상태는 조회 시점에 따라 달라질 수 있습니다. 기대 파일 수는 추출 성공 파일 수가 아닙니다.
